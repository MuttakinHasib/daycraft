## Target structure (grow into it; do not scaffold empty folders)

```text
src/
  app/                       # routes only (see navigation-and-modules.md)
  features/
    today/                   # TodayScreen parts: DateHeader, WeekStrip, HabitRow, Timeline/*, hooks
    timeline/                # if the timeline is used by more than Today, it moves here
    inbox/  calendar/  upcoming/  tasks/  habits/  routines/  goals/  projects/  focus/  journal/
    activity-editor/         # editor + detail sheets (shared by every entry point)
  components/ui/             # primitives only
  domain/
    time.ts                  # date/time utilities and formatting
    timeline/                # layout, time map, gaps, slots, snapping, next free slot
    activity.ts  habit.ts  routine.ts  goal.ts  project.ts  journal.ts  inbox.ts
  data/                      # repositories + fixtures
  hooks/                     # cross-feature hooks only (useNow, useSelectedDate)
```

A feature folder holds that module's screens' building blocks, its hooks, and its tests. If something is used by two features, move it: to `components/ui` (visual), `domain` (logic) or `hooks` (cross-cutting).

## Naming

| Thing | Convention | Example |
|---|---|---|
| Files | kebab-case | `check-ring.tsx`, `week-strip.tsx`, `use-now.ts` |
| Route files | Expo Router conventions | `index.tsx`, `[projectId].tsx`, `_layout.tsx` |
| Components | PascalCase named export (default export only for route files and where the router requires it) | `export function WeekStrip` |
| Hooks | `useX` in `use-x.ts` | `useDayActivities` |
| Props types | `interface XProps` next to the component | `interface ChipProps` |
| Domain functions | verbs, no abbreviations | `layoutDay`, `findNextFreeSlot`, `formatTimeRange` |
| Constants | `SCREAMING_SNAKE_CASE` for true constants; `as const` objects for enums | `DAY_START_MINUTES`, `ActivityHue` |
| Tests | `*.test.ts(x)` next to the file | `layout-day.test.ts` |
| Domain terms | from the [vocabulary](../product/product-overview.md#vocabulary) | `Activity`, `Capsule`, never `Item` |
