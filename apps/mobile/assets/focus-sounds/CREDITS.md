# Focus ambient sounds — sources and licences

The five loops Focus bundles. Every one is CC0 (a public-domain dedication) — the licence was
read on the sound's own page before downloading, and the licence line as that page shows it is
recorded below. No music, no songs, and nothing from the Nahian site.

Each in-app file is a processed cut of its source, not the source file itself: trimmed to a
20–60 second loop, downmixed to mono, loudness-matched to about −23 LUFS, and re-encoded as
64 kbps AAC. For the cuts that were not already seamless loops, the tail is crossfaded into the
head so the loop point is inaudible. Processing notes are per file.

The Freesound files are the publicly downloadable preview encodings of their recordings
(`cdn.freesound.org/previews/…-hq.mp3`); the licence above, shown on each recording's page,
covers the recording and therefore these cuts of it.

## Processing notes

- `brown-noise.m4a` — cut 120–165.06 s of the 15-minute original, 60 ms seam crossfade, −6.0 dB, 45.1 s.
- `cafe.m4a` — cut 7–49.6 s, 600 ms seam crossfade, +15.9 dB with a −1 dB peak limit, 42.6 s.
- `forest.m4a` — cut 280–330.7 s of the dawn-chorus recording, 700 ms seam crossfade, +7.5 dB, 50.7 s.
- `rain.m4a` — cut 5–60.08 s of the looping rainfall, 80 ms seam crossfade, +5.7 dB, 55.1 s.
- `waves.m4a` — the full 21.8 s source, which is already a seamless loop, so no crossfade; +15.6 dB with a −1 dB peak limit.
