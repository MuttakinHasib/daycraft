# Daycraft web

The Next.js 16 app (`@daycraft/web`) in the Daycraft monorepo, for desktop and tablet.

```bash
bun install          # from the monorepo root
bun run dev          # http://localhost:3000
bun run check-types  # next typegen && tsc --noEmit
bun run lint
bun run build        # catches Cache Components and prerender errors
```
